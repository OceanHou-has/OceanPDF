# PDF导出字体目录

此目录存放 PDF 导出所需的字体文件。

## 当前字体配置（已就绪）

| 字体文件 | 用途 | 状态 |
|----------|------|------|
| `NotoSansSC-Regular.ttf` | 中英文主字体 | ✅ |
| `NotoSansSC-Bold.ttf` | 中英文粗体 | ✅ |
| `NotoSansMath-Regular.ttf` | 数学符号 | ✅ |
| `NotoSansSymbols-Regular.ttf` | 特殊符号 | ✅ |

## 字体来源

- **Noto Sans SC**: https://fonts.google.com/noto/specimen/Noto+Sans+SC
- **Noto Sans Math**: https://fonts.google.com/noto/specimen/Noto+Sans+Math
- **GitHub Release**: https://github.com/googlefonts/noto-cjk/releases
